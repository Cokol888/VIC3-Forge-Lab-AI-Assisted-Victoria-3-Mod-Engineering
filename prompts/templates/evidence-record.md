# Evidence Record Template

```yaml
evidence:
  claim:
  type: LOCAL_TEST
  source:
  environment:
    game_version:
    checksum:
    modset: []
    commit:
  status: VERIFIED
  verified_at:
  revalidation_trigger: []
  notes:
```

Use `REVALIDATION_REQUIRED` after relevant environment changes. Use `INVALIDATED` only when contrary evidence exists.
