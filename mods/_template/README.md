# Mod Workspace Template

Copy this directory to `mods/<mod-id>/` and replace placeholder values.

Recommended structure:

```text
engineering/
  STATE.md
  DECISIONS.md
  EVIDENCE.md
  REGRESSIONS.md
  gates/
  checkpoints/
  experiments/
  sessions/
tests/
  static/
  runtime/
  regression/
  compatibility/
  balance/
mod/
  .metadata/
  common/
  events/
  gui/
  gfx/
  localization/
releases/
```

Create only Victoria 3 directories actually used by the mod. Empty placeholder game directories are not required.
