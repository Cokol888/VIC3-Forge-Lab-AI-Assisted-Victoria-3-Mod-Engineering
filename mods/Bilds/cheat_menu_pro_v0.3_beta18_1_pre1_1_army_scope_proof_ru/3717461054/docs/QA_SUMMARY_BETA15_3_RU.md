# QA beta15.3 — Economy-in-Shell

Дата проверки: 2026-08-18.

## Реализовано

- Экономика включена в левую навигацию Global UI Shell.
- Видимая кнопка `ECON 2.0` открывает страницу экономики в Shell.
- Разделы «Деньги», «Модификаторы» и «Собственность» имеют независимую прокрутку.
- Сгенерированы отдельные компоновки для профилей 90/100/115/130.
- Статус страновой цели и переход к Центру целей встроены в страницу.
- Результат операции перенесён в закреплённую нижнюю строку.
- Прежнее окно сохранено как аварийный fallback без видимой точки переключения.
