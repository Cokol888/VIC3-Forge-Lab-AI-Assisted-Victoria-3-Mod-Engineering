# Politics & Characters 2.0 — beta15

Beta15 adds a unified, accessibility-first controller for government, characters, interest groups, current law enactment, and a deliberately narrow Power Bloc cohesion tool. Legacy B3/B5/B9 remain available for mechanics not yet migrated through the future Vanilla Rework.

Country actions use Unified Target Core (Player / Marked Country / Group A/B/C). Character actions require the Character target and a marked CMP character. Power Bloc cohesion requires the Power Bloc target.

Government supports isolated Politics2 modifiers for legitimacy, authority, bureaucracy and influence, plus exact investment levels 1–5 for seven existing standard institutions.

Character tools include immortality, explicit health/popularity bonus modifiers, commander ranks, General/Admiral roles, and six quick traits. Biological age is intentionally read-only because no safe direct SET-age effect was confirmed in the inspected 1.13.x surface.

Interest Group tools operate on selected standard IG types: approval modifiers and political-strength multipliers. The UI explicitly states that political strength is not a fixed clout value.

Law tools act only on countries currently enacting a law: checkpoint progress, phase, setback, complete, cancel, and clear enactment modifiers.

Power Bloc scope is intentionally limited to cohesion in beta15; membership, principles, and leverage remain Legacy until audited.
