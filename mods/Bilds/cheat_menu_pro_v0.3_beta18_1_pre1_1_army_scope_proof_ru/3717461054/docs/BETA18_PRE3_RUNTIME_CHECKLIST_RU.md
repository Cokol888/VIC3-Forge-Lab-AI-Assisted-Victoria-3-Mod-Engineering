# Runtime checklist — beta18-pre3 Fleet Composer 2.0

## Gate A — regression beta18-pre2.4

1. Открыть `Флот → Выбранный флот → Выбрать / изменить флот`.
2. Убедиться, что собственные флоты отображаются.
3. Проверить row-level scope indicators из pre2.4.
4. Нажать на строку флота и убедиться, что открывается штатная карточка именно этого флота.

Если этот regression ломается, тест Fleet Composer прекращается.

## Gate B — базовый Composer 2.0

1. Отметить собственную область с портом.
2. Открыть `Флот → Конструктор флота 2.0`.
3. Проверить пять строк состава и отдельный picker корпуса каждой строки.
4. В picker ранней эпохи должны присутствовать Ship of the Line / Frigate и другие vanilla hulls; T&R поздние hulls видны, но блокируются provider/technology gate при недоступности.

## Gate C — два типа

Пример:

- Row 1: Ship of the Line ×1;
- Row 2: Frigate ×3;
- Rows 3–5: 0.

Нажать `Создать один флот`.

Ожидание: появляется **ровно одна** новая fleet formation с суммарно четырьмя кораблями и обоими типами.

## Gate D — три и пять типов

Повторить:

- 3 ненулевые строки;
- затем 5 ненулевых строк.

Каждый раз должна появляться одна новая formation, а не несколько отдельных флотов.

## Gate E — повтор одного корпуса

- Row 1: Frigate ×3;
- Row 2: Frigate ×5;
- остальные 0.

Ожидание: один новый флот, итог — 8 Frigate. Если движок не суммирует одинаковый Ship Type корректно, зафиксировать фактическое поведение и не принимать pre3.

## Gate F — presets

1. Нажать Escort.
2. Убедиться, что строки изменились, но флот ещё не создан.
3. Нажать Battle/Carrier/Wolfpack/Amphibious Support и проверить то же правило.
4. Создание выполняется только отдельной кнопкой.

## Gate G — отрицательные состояния

- нет отмеченной собственной портовой области;
- количество >0, но корпус строки не выбран;
- выбран закрытый технологией корпус;
- выбран T&R hull без активного provider;
- все строки = 0.

Никакого silent fallback на другой корпус или другой порт быть не должно.

## Gate H — время и persistence

Для одного 3–5-row флота:

1. записать состав сразу после создания;
2. промотать +1 день;
3. сделать save/load;
4. сравнить число кораблей и их типы.

## Gate I — интерфейс

Smoke на Workspace profiles 90 / 100 / 115 / 130:

- все пять строк доступны через scroll;
- picker корпуса прокручивается;
- длинные RU labels не перекрывают кнопки;
- selected hull виден;
- create/reset/presets доступны;
- fixed footer не перекрывается содержимым.

### Критерий PASS

Fleet Composer 2.0 принимается только если 2/3/5-row сценарии создают по одной formation, duplicate-hull сценарий имеет предсказуемый аддитивный результат, negative states честны, а immediate/+1 day/save-load не меняют состав неожиданно.
