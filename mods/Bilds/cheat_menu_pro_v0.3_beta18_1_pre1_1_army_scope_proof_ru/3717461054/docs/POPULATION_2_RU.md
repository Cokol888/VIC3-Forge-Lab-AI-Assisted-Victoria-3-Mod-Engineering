# Population & Society 2.0 — beta14

## UI profile

- Primary layout target: **2560×1080**.
- Secondary ultrawide target: **3440×1440**.
- New primary controls use 44–52 px heights and 12–14 pt text where the CMP GUI allows it.
- The original POP page remains available as **Legacy POP UI**.

## New direct mechanics

- Add/remove population per target state.
- Exact literacy SET.
- Profession-specific qualified cohort creation.
- Exact qualification SET for a selected profession.
- Exact pop wealth SET.
- Loyalists/radicals adjustment and neutralization.
- Population 2.0 migration pull and working-adult-ratio state modifiers.
- Confirmed mass culture assimilation and state-religion conversion.
- Industrial workforce, education and stabilization presets.

Population 2.0 only accepts Target Core state modes (home marked states, incorporated states, foreign marked states) to keep mass population actions explicit.
