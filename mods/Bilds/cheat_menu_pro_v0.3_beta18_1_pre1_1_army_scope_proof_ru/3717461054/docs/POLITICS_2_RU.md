# Politics & Characters 2.0 — beta15

Beta15 объединяет новые безопасные контроллеры для персонажей, правительства, групп интересов, текущего принятия закона и ограниченного набора операций с блоком держав. Legacy-страницы B3/B5/B9 не удаляются: они остаются доступными для функций, которые ещё не прошли Vanilla Rework.

## Цели

Страновые действия используют Unified Target Core и поддерживают:

- Игрок;
- отмеченную страну;
- Group A / B / C.

Персонажи требуют режима **Персонаж** в Target Core и реально отмеченного персонажа CMP. Блок держав требует режима **Блок держав** и корректно отмеченную страну, состоящую в блоке.

Неподходящие типы целей не приводят к silent no-op: кнопки недоступны или возвращают явный статус.

## Правительство

Доступны четыре изолированных модификатора Politics 2.0:

- базовая легитимность: +10 / +25 / +50 / +100;
- authority: +10 / +25 / +50 / +100%;
- bureaucracy: +10 / +25 / +50 / +100%;
- influence: +10 / +25 / +50 / +100%.

`Сбросить наши модификаторы` удаляет только модификаторы beta15 и не затрагивает legacy CMP.

### Институты

Для семи стандартных институтов можно выставить уровень 1–5. Операция применяется только к странам, у которых выбранный институт уже существует; остальные страны в A/B/C пропускаются.

Поддерживаются: Colonial Affairs, Schools, Social Security, Workplace Safety, Police, Health System, Home Affairs.

## Персонажи

Подтверждённые операции:

- бессмертие ON/OFF;
- бонус здоровья +0.05 / +0.20 / +1.00 и reset;
- популярность +5 / +25 / +100 и reset;
- ранг командира 1–5;
- добавить/удалить роль General;
- добавить/удалить роль Admiral;
- добавить/удалить быстрые traits: ambitious, charismatic, brave, innovative, meticulous, persistent.

Здоровье и популярность обозначены именно как **бонусы-модификаторы**, а не как точный SET внутреннего значения.

### Возраст

В beta15 биологический возраст оставлен read-only. В проверенном публичном effect surface 1.13.x не подтверждён безопасный direct SET возраста; изменение career length не является эквивалентом возраста персонажа.

## Interest Groups

Можно выбрать одну или несколько из восьми стандартных IG и применить операции ко всем выбранным типам в странах-целях.

### Approval

+5 / +10 / +20 / -5 / -10 / reset.

### Political Strength

+25 / +50 / +100 / +500 / -50% / reset.

Важно: это **множитель political strength**, а не установка фиксированного clout. Clout остаётся относительным результатом распределения политической силы.

## Текущий закон

Для стран, где идёт принятие закона:

- +10% прогресса текущего checkpoint;
- +25% прогресса;
- следующая фаза;
- добавить setback;
- немедленно принять текущий закон;
- отменить принятие;
- очистить enactment modifiers.

В группах A/B/C страны без активного принятия закона пропускаются и не считаются ошибкой остальных целей.

## Блок держав

Beta15 сознательно переносит только **cohesion**:

- +25;
- +50;
- -25;
- установить 100.

Membership, principles и leverage остаются в Legacy CMP до отдельного Vanilla Rework, поскольку эти операции шире и потенциально разрушительнее.

## UI Accessibility

Politics 2.0 следует стандарту beta14:

- основной профиль: 2560×1080;
- второй профиль: 3440×1440;
- основные шрифты/контролы не мельче установленного accessibility gate;
- RU/EN parity проверяется автоматически;
- выбранное состояние не изображается как disabled.

Статические проверки не заменяют runtime-проверку clipping и UI Scale в Victoria 3.
