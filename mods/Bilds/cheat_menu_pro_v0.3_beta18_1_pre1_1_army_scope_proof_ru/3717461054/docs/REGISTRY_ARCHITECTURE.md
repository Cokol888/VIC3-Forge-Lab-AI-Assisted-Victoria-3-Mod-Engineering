# CMP v0.3-beta11 — Registry / Code Generation Architecture

Beta11 introduces JSON registries as the source of truth for providers, buildings, resources, land units, ships and operations. Production Fleet Builder scripted GUI/effects and the Fleet Builder ship-selector GUI block are generated by `tools/generate_registry.py`.

The ship-selector block in `sakuya_main.gui` is bounded by explicit `CMP_REGISTRY_BEGIN/END fleet_ship_selector` markers, so codegen replaces only that section rather than rewriting the whole large GUI file.

Current provider adapters use the existing `community_framework_is_active` and `technres_is_active` detection triggers. Run `python3 tools/generate_registry.py --check` before packaging and `tools/validate_release.py --overlay <full base-mod overlay>` for full cross-reference validation.

Beta12 will consume the building/resource registries for Regions & Buildings 2.0 and PM-aware Staffing.
