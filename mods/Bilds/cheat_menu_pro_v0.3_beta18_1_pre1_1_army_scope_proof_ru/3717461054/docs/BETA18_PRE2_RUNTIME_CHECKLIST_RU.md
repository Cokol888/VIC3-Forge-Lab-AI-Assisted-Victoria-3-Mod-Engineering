# Runtime checklist — beta18-pre2

Статический PASS не считается runtime PASS. Проверить в Victoria 3:

1. Полностью заменить текущий `3717461054` содержимым beta18-pre2 и перезапустить игру.
2. Workspace → Армия и флот → Флот → `Корабли и шаблоны`.
3. Убедиться, что видны ранние корпуса: Ship of the Line / Frigate и последующие технологические поколения, а не только T&R modern hulls.
4. Проверить категории: Все / Крупные / Крейсеры / Торпедные / Tech & Res.
5. Проверить `Показывать устаревшие`: после исследования технологий старые vanilla hulls должны скрываться/возвращаться без изменения gameplay-state.
6. Нажать `Открыть конструктор кораблей`: при наличии Ship Designer feature должен открыться штатный Ship Designer Victoria 3.
7. В штатном дизайнере проверить создание/редактирование пользовательского шаблона; CMP не должен дублировать окно и не должен создавать template сам.
8. Отметить собственную портовую область и создать x1 Frigate/Ship of the Line или другой доступный ранний hull. Должен появиться один новый fleet.
9. Проверить x3/x5/x10 на разных группах; закрытая технология должна корректно блокировать create.
10. Проверить T&R hull при активном provider и поведение при недоступном provider.
11. Переключиться в `Смешанный флот`: pre1 composer должен по-прежнему создавать одну mixed formation.
12. Переключиться в `Выбранный флот`: exact Fleet Selector и add-ships compatibility path не должны регрессировать.
13. Проверить порт отсутствует / область чужая / технология закрыта: silent no-op запрещён.
14. Промотать +1 день; затем save/load и повторно проверить созданный флот.
15. Smoke профилей Workspace 90/100/115/130 и RU-текста/scroll.

Особенно важный результат: native Ship Designer должен открываться из CMP без конфликта со Workspace. Если окно не открывается или ломает фокус/закрытие Workspace — это отдельный узкий bridge hotfix, а не повод переписывать designer внутри CMP.
