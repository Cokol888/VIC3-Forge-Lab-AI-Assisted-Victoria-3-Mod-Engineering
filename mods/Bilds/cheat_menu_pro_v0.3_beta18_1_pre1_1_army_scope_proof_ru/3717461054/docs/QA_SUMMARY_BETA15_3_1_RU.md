# QA beta15.3.1 — UI Density Hotfix

Дата проверки: 2026-08-18.

## Реализовано

- Старый фиксированный tray целей удалён вместе с шестью статусными сегментами.
- Отдельная кнопка `ЭКОНОМИКА 2.0` в старой рабочей области удалена.
- Оставлена одна кнопка `РАБОЧАЯ ОБЛАСТЬ`, открывающая новую область и сохраняющая последнюю страницу сессии.
- В Economy Shell используются короткие названия вкладок: `Деньги`, `Модификаторы`, `Собственность`.
- Длинные описания обзора и трёх разделов убраны из постоянной компоновки.
- Для обзора, денег, модификаторов и собственности добавлены составные hover-подсказки и закрепляемые прокручиваемые справочные карточки.
- Активная цель и результат операции остаются постоянно видимыми.
- Техническая строка миграции удалена из навигации.
- Экономические эффекты и их ScriptedGui endpoint’ы не изменялись.

## Новые статические инварианты

- ровно один launcher рабочей области;
- отсутствие `cmp_ui_target_bar`;
- отсутствие отдельного legacy Economy launcher;
- четыре help-карточки и 16 прокручиваемых help-layout’ов;
- паритет компактных подписей для профилей 90/100/115/130;
- отсутствие длинных Economy-описаний в постоянном слое Shell;
- видимый статус цели и видимая нижняя строка результата;
- минимальная высота пользовательской кнопки Shell — 44 пикселя;
- RU/EN parity для всех новых ключей.
