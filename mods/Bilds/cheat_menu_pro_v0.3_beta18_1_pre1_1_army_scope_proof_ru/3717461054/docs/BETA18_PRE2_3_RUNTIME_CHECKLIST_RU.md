# beta18-pre2.3 — Runtime checklist: Native Fleet Selection

Цель: доказать, что Victoria 3 native selection является надёжным источником exact existing-fleet target и операция выполняется непосредственно над выбранной `MilitaryFormation`.

## 1. Чистый старт

1. Полностью заменить текущий каталог `3717461054` содержимым beta18-pre2.3.
2. Перезапустить Victoria 3.
3. Открыть Workspace → Армия и флот → Флот → Выбранный флот.

## 2. Native selector

1. Нажать «Выбрать / изменить флот».
2. У строки каждого собственного флота должен присутствовать жёлтый scope-probe.
3. Нажать Fleet A.
4. В верхней диагностике ожидается «Victoria 3: флот выбран».
5. Справа ожидается «Контекст военного формирования готов».
6. Закрыть picker: в основной строке должно отображаться точное имя Fleet A.
7. Открыть picker и выбрать Fleet B: основная строка должна сразу переключиться на B без очистки CMP-marker, потому что marker production-path больше не используется.

## 3. Exact operation A/B

Подготовить два различимых флота A и B.

1. Выбрать A.
2. Выбрать доступный тип корабля и `+1`.
3. Выполнить «Добавить корабли».
4. Проверить: изменился только A.
5. Выбрать B.
6. Выбрать тип и `+3`.
7. Проверить: изменился только B, A повторно не изменился.

FAIL, если корабль попал в первый подходящий/случайный/предыдущий флот.

## 4. Пустой флот

1. Создать/найти собственное Fleet formation без кораблей.
2. Выбрать его native selector.
3. Добавить `+1` доступного корпуса.
4. Ожидание: первый корабль создаётся именно в пустом выбранном Fleet.

## 5. Army negative case

1. Штатным интерфейсом Victoria выбрать армейскую formation.
2. Вернуться/оставить Workspace открытым.
3. Ожидание: CMP показывает «Выбрана армия, а не флот»; кнопка добавления кораблей недоступна.
4. Выбрать Fleet — действие снова доступно.

## 6. Battle gate

1. Выбрать Fleet, в котором хотя бы один существующий Ship находится в бою.
2. Ожидание: красная индикация; добавление кораблей заблокировано.
3. После выхода из боя операция снова становится доступна.

## 7. Tick и save/load

1. После успешного A/B теста промотать +1 день и проверить оба флота.
2. Сохранить игру и загрузить её.
3. Допустимы два корректных исхода после load:
   - Victoria восстановила native selection — CMP показывает этот Fleet;
   - native selection сброшен — CMP честно показывает «Флот не выбран».
4. Недопустимо: CMP самопроизвольно восстанавливает старую/уничтоженную цель или операция применяется к ghost target.

## Runtime PASS

PASS ставится только если A→+1 меняет A, B→+3 меняет B, Army блокируется, пустой Fleet принимает первый Ship, battle gate работает и после tick/save-load отсутствует ghost-target.
