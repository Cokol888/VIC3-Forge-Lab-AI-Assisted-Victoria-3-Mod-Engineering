# Runtime checklist — beta18-pre1 Navy Architecture

## A. Новый флот

- [ ] Workspace → Армия и флот → Флот → **Новый флот** открывается без layout-дефекта.
- [ ] Без отмеченной собственной портовой области Create недоступен.
- [ ] Отметить собственную область с портом: статус становится готовым.
- [ ] Destroyer ×5 → создаётся один флот с выбранным типом.
- [ ] Destroyer ×5 + Cruiser ×3 → создаётся **один** флот, а не два.
- [ ] Destroyer ×5 + Cruiser ×3 + Battleship ×1 → один mixed fleet.
- [ ] Добавить Carrier/Submarine при открытых технологиях и проверить тот же one-formation contract.
- [ ] Выбрать закрытый technology ship: UI показывает technology block, Create не выполняется.
- [ ] Clear сбрасывает все пять количеств.

## B. Шаблоны

- [ ] Escort загружает состав, но не создаёт флот автоматически.
- [ ] Battle загружает состав, но не создаёт флот автоматически.
- [ ] Carrier загружает состав, но не создаёт флот автоматически.
- [ ] Wolfpack загружает состав, но не создаёт флот автоматически.
- [ ] Amphibious Support загружает состав, но не делает auto-attach армии.
- [ ] После загрузки preset можно изменить отдельную строку перед Create.

## C. Target / HQ

- [ ] Одна отмеченная собственная портовая область → используется её HQ context.
- [ ] Отмеченная внутренняя область без порта не считается valid target.
- [ ] Несколько отмеченных портовых областей → создание остаётся детерминированным; ожидается highest-GDP state.

## D. Выбранный существующий флот

- [ ] Переключение **Выбранный флот** открывает exact Fleet Selector beta17.
- [ ] Выбирается конкретный флот и сохраняется зелёный marker.
- [ ] Add ship применяется только к выбранному exact fleet.
- [ ] Clear target очищает exact target.
- [ ] Нет возврата one-shot event picker или hidden first-fleet fallback.

## E. Persistence / UI

- [ ] Проверить результат сразу.
- [ ] Промотать +1 день.
- [ ] Save/load и проверить созданный mixed fleet.
- [ ] Smoke profiles 90/100/115/130.
