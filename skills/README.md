# VIC3 Forge Skills

This directory stores reusable ChatGPT skills that operate against the live VIC3 Forge Lab repository.

## Available

### `vic3-forge-engineering`

Live-repository engineering control plane for Victoria 3 design, implementation, debugging, migration, QA, regression, and continuation work.

The skill intentionally bundles workflow knowledge and repository contracts rather than copies of large mod files or prompt archives. It retrieves current project state from GitHub when used.

See `catalog/skills.yml` for machine-readable registration.
